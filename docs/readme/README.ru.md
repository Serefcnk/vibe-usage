# Vibe Usage

**Все ваши платные подписки на ИИ для программирования — в одном окне строки меню.**

Смотрите, сколько квоты осталось в Claude Code, Codex, Cursor и Antigravity, запускайте инструмент, у которого ещё есть
запас, и передавайте недоделанную задачу из одного инструмента в другой, не объясняя её заново.

Трей Windows · строка меню macOS · 13 языков · без паролей, токены не сохраняются

**[Скачать для Windows и macOS](https://github.com/mustafacagri/vibe-usage/releases/latest)** · Терминал: `npm install -g vibe-usage-cli`

## Зачем

Если вы пишете код с несколькими ИИ-инструментами, то постоянно упираетесь в одну и ту же стену: 5-часовой лимит
заканчивается посреди задачи, вы открываете другой инструмент и объясняете всё с самого начала. Каждый сервис
показывает расход в своём месте, а некоторые не показывают вовсе.

Vibe Usage читает сессии, в которые вы уже вошли на этом компьютере, и показывает все лимиты рядом: сколько осталось и
когда произойдёт сброс. Когда в одном инструменте квота подходит к концу, он запускает следующий с подтверждённой
квотой в папке проекта и записывает сводку текущей сессии, чтобы новый инструмент продолжил с того места, где
остановился прежний.

### Несколько аккаунтов

## Поддерживаемые инструменты

| Инструмент  | Откуда берётся квота                                                     | Сессии для передачи                            | Запуск                                   |
| ----------- | ------------------------------------------------------------------------ | ---------------------------------------------- | ---------------------------------------- |
| Claude Code | OAuth-эндпоинт расхода профиля (связка ключей в macOS)                   | `~/.claude/projects`                           | CLI `claude` с выбранным профилем        |
| Codex       | Методы лимитов app-server установленного CLI                             | `~/.codex/sessions`                            | CLI `codex`                              |
| Cursor      | Сводка расхода текущей сессии                                            | Чаты Cursor Agent CLI (`~/.cursor/chats`)      | `cursor-agent`, иначе приложение         |
| Antigravity | Локальная служба запущенного приложения (владелец процесса и порта проверяется) | `~/.gemini/antigravity-ide`             | Приложение Antigravity                   |

Списки моделей берутся из данных каждого инструмента: псевдонимы Claude Code и модели, которыми вы пользовались, кэш
моделей Codex и `cursor-agent --list-models` (кэшируется на 24 часа).

## Конфиденциальность и безопасность

- **Только чтение.** Использует уже существующие сессии. Никогда не просит пароль, не сохраняет токены,
  не выполняет выход из аккаунтов и не трогает текущую работу.
- **Истёкший вход.** Когда работа может сама переходить между аккаунтами, истёкший вход в Claude Code обновляет сам Claude Code: одним минимальным запросом к Haiku (одно слово, без инструментов, ничего не сохраняется), не чаще раза в 30 минут на аккаунт. Приложение никогда не читает и не использует токен обновления.
- **Два эндпоинта.** Запросы квот идут только на эндпоинты расхода Anthropic и Cursor, с включённой проверкой TLS.
  Codex и Antigravity читаются локально.
- **Никаких секретов на диске.** Настройки хранятся в `%APPDATA%\Vibe Usage\settings.json` (Windows) или
  `~/Library/Application Support/Vibe Usage/settings.json` (macOS). Квоты держатся только в памяти.
- **Защищённое приложение.** Окно работает в песочнице со строгой CSP, не может переходить на другие страницы или
  открывать окна и отвечает только своей странице. Fuse-флаги Electron отключают `runAsNode`, `NODE_OPTIONS` и
  инспектор и включают проверку целостности ASAR.

## Установка

### Windows

Скачайте `Vibe-Usage-<версия>-win-setup.exe` из [последнего релиза](https://github.com/mustafacagri/vibe-usage/releases/latest) и запустите: он устанавливается только для вашего пользователя, без прав администратора. Или возьмите портативный `Vibe-Usage-<версия>-win-x64.zip` (или `-arm64`), распакуйте и запустите `Vibe Usage.exe`. Приложение живёт в области уведомлений и даёт ссылку на каждую новую версию.

Приложение не подписано, поэтому при первом запуске Windows SmartScreen может показать **Система Windows защитила ваш компьютер**. Нажмите **Подробнее**, затем **Выполнить в любом случае**.

### macOS

Скачайте `Vibe-Usage-<версия>-mac-arm64.dmg` (Apple silicon) из [последнего релиза](https://github.com/mustafacagri/vibe-usage/releases/latest), откройте его и перетащите **Vibe Usage** в «Программы». Приложение ещё не подписано Apple Developer ID, поэтому Gatekeeper блокирует первый запуск: откройте **Системные настройки › Конфиденциальность и безопасность** и нажмите **Все равно открыть** или выполните:

```sh
xattr -dr com.apple.quarantine "/Applications/Vibe Usage.app"
```

На Mac с Intel, или чтобы пропустить этот шаг, соберите приложение сами. Нужен только Node.js 24:

```sh
git clone https://github.com/mustafacagri/vibe-usage.git && cd vibe-usage
npm ci
npm run build:mac
cp -R "release/mac-arm64/Vibe Usage.app" /Applications/
```

На Mac с Intel папка называется `release/mac`. Собранное вами приложение не попадает в карантин и открывается сразу. Приложение даёт ссылку на каждую новую версию, она ставится так же.

## Командная строка

Те же данные доступны в терминале, в Windows и macOS, с настольным приложением или без него. Нужен Node.js 24 или новее; CLI читает те же сессии с выполненным входом, что и приложение, а если установлены оба, у них общие настройки и язык.

```sh
npm install -g vibe-usage-cli
vibe-usage status
```

<img src="../media/cli.png" width="640" alt="vibe-usage status в терминале: все окна двух аккаунтов Claude, двух Codex, одного Cursor и двух Antigravity" />

```sh
vibe-usage status [--json]   # квота всех аккаунтов один раз; --json для скриптов
vibe-usage watch             # то же самое, обновляется до Ctrl+C
vibe-usage run <claude|codex|cursor> [--account ID] [--cwd PATH] [--model MODEL] [--dry-run]
vibe-usage handover [--from TOOL] [--to TOOL] [--session ID] [--cwd PATH]
vibe-usage help
```

Чтобы попробовать без установки, выполните `npx vibe-usage-cli status`.

`run` запускает инструмент в этом терминале с аккаунтом, квота которого подтверждена; иначе укажите аккаунт через `--account` (ID есть в `status --json`). `--dry-run` выводит аккаунт и команду, ничего не запуская. `handover` записывает `VIBE_HANDOVER.md` для последней сессии папки (или `--session`) и открывает с ним целевой инструмент.

## Ограничения

- Сборка для macOS не нотаризована (см. [macOS](#macos)).
- Модель сессии Antigravity берётся из недокументированной локальной записи; если её не удаётся прочитать, поле остаётся
  пустым.
- Чаты Cursor IDE (Composer) передать нельзя; читаются только сессии Cursor Agent CLI.
